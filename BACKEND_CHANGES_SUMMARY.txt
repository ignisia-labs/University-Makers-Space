Overview
I added a complete production-oriented backend service in the new backend/ folder.
The existing Lovable/TanStack frontend was left untouched.

- Added Prisma/PostgreSQL database schema with UUID primary keys.

Important Notes
- The backend server was not started because it needs real environment variables,
  PostgreSQL, Redis, and Cloudinary credentials.
- To run locally:
  1. cd backend
  2. copy .env.example to .env
  3. fill in real DATABASE_URL, REDIS_URL, JWT secrets, Cloudinary credentials, and FRONTEND_URL
  4. run npm run prisma:migrate
  5. run npm run prisma:seed
  6. run npm run dev
